Wi-Fi Configuration

Connect the device to your local wireless network for time synchronization and automatic data uploads.

Set your local timezone so timestamps on recorded sleep files are accurate.

Advanced settings

3 Automatic Uploads (Data Destinations)
Network Folder (SMB Share)

Automatically save recorded sleep files directly to a home server, NAS, or Windows shared folder.

smb://guest:@192.168.1.100/sleep/SomnoTrace
SleepHQ Cloud Upload

Automatically upload therapy records to your SleepHQ.com account for online sleep analysis and sharing.

4 Remote File Access (FTP Server)
SD Card File Access (FTP)

Allow computers or mobile devices on your Wi-Fi network to browse and download recorded sleep files directly from the SD card using an FTP client.

Maintenance Actions

These actions modify files on the SD card and upload state. Each action requires confirmation before proceeding.

Reset Upload State
Clears upload tracking so all days re-upload from the beginning
Delete All EDF Files
Removes all EDF and related files from SDCARD/ (session data preserved)
Recreate EDFs from Sessions
Deletes all EDFs and re-exports them from .session files in chronological order
Reset ALL (Destructive)
Deletes everything under /somnotrace/ (SDCARD + .sessions) and clears upload state
